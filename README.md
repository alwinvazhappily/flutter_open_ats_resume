# OpenATSResume - Flutter

OpenATSResume is an open-source, ATS-friendly resume and cover letter generator built with Flutter. This project helps users create optimized resumes and cover letters that pass Applicant Tracking System (ATS) scans, ensuring better job application success.

## Features

✅ **ATS-Friendly Resume Generator** – Create resumes that are optimized for ATS systems.  
✅ **Cover Letter Builder** – Generate personalized cover letters.  
✅ **Google & Apple Sign-In** – Secure authentication using Firebase.  
✅ **Cloud Storage** – Store resumes and cover letters using Firestore.  
✅ **Completely Free & Open Source** – Funded by donations via Buy Me a Coffee.  

## Getting Started

### Prerequisites

- Install [Flutter](https://flutter.dev/docs/get-started/install)
- Install [Git](https://git-scm.com/downloads)
- Set up a Firebase project and configure authentication

### Clone the Repository

```bash
git clone https://github.com/alwinvazhappily/flutter_open_ats_resume.git
cd flutter_open_ats_resume
```

### Install Dependencies

```bash
flutter pub get
```

### Run the Application

```bash
flutter run
```
